# Track B external tasks

These records separate source metadata from ABI's D1 adaptation. A task whose
`freeze_status` ends in `pending` is excluded from confirmatory execution until
the exact upstream prompt/capsule, its applicable license, and all data hashes
have been verified. This prevents a metadata stub from being presented as a
completed external benchmark freeze.

BioAgent Bench repository-authored content is CC-BY-4.0; third-party datasets
retain their original terms. CORE capsule terms are recorded per capsule at
import time.
